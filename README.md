# Organo

Projeto básico para criar organogramas simples.  
Você pode conferir o design system deste projeto [aqui](<https://www.figma.com/design/KeUkh6K4vDbhGEpYm8o1Qx/React%3A-desenvolvendo-com-JavaScript-%7C-Organo-(Community)?node-id=134-143&t=4QgpJLYg111Qces5-0>).

## Executando

Basta rodar o comando abaixo na raiz:

### `npm start`

Abra [http://localhost:3000](http://localhost:3000) para visualizar no navegador.
